Importar questões (JSON)

Cole um array de questões no formato aceito (veja "Ver exemplo"). "comando" é obrigatório — é o que o aluno precisa responder (ex.: "Considerando essas informações, qual é o percentual..."). "enunciado" (texto de apoio) e "imagem" são opcionais e independentes — pode ter só um dos dois, os dois, ou nenhum, se o "comando" já se basta sozinho. A ordem dos campos no JSON não importa. "fonte" é opcional. Campos inválidos ou ausentes serão reportados abaixo.
